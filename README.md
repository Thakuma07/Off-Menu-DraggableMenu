# Off/Menu Animation & Hero Header

A premium, interactive web experience featuring a dynamic, draggable menu drawer and a high-impact hero section with a video background and glassmorphism elements.

## ✨ Features

- **Draggable Menu Drawer**: A floating menu that can be dragged across the top zone and snaps into place.
- **Expandable Interaction**: Smooth GSAP-powered expansion to reveal navigation items (Work, Manifesto, Contact).

- **Hero Video Background**: High-quality video background for an immersive visual experience.
- **Glassmorphism UI**: 
  - Glassmorphic menu drawer with backdrop blur.
  - Interactive buttons with frosted glass hover effects.
- **Responsive Layout**: Wrapped in a sleek, rounded main container inspired by modern interface design.
- **GSAP Animations**: Fluid transitions for menu items and drawer expansion.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure.
- **CSS3**: Advanced layouts, glassmorphism (backdrop-filter), and transitions.
- **JavaScript (ES6+)**: Core logic for interactions.
- **GSAP (GreenSock Animation Platform)**: Powering the smooth expansion and staggered item reveals.
- **GSAP Draggable**: Enabling the intuitive drag-and-drop behavior for the menu.
